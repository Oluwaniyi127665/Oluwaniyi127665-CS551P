# Raw Data Files

Place the downloaded government CSV files in this folder using these filenames:

- `educational-establishment.csv`
- `local-authority.csv`

Recommended source pages:

- https://www.planning.data.gov.uk/dataset/educational-establishment
- https://www.planning.data.gov.uk/dataset/local-authority

For coursework submission, load a subset of about `3000-5000` schools so the final app stays inside the `2000-7000` record requirement.
